Every story was verified against primary reporting (QNA, Reuters, UEFA, NATO, NWS) as an event of 26 November 2026 in some timezone. The Champions League matches ended after midnight in Asia-Pacific time; the Kim visit happened Wednesday but was first reported Thursday, which the rules allow. The Trump–Rutte dinner is dated by its 7 p.m. ET start, which is midnight UTC Thursday. Forward-looking wording is used where the event is scheduled, not yet happened (Chess Game 3).
